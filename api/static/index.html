Contract watchlist

Department of Veterans Affairs · contracts signed between October 2017 and September 2018

The problem

The government signs a contract at one price. Many end up costing more, because work gets added after signing. That extra spending is public record — but there were — contracts in this one year, and nobody has time to read them all.

What this list is

Every contract is scored on the day it was signed, using only what was known that day. The ones most likely to cost more are put at the top. A reviewer reads 200 instead of all of them.

How to use it

Start at the top and work down. A contract near the top is one worth a closer look — not one that has done anything wrong. Most contracts grow for good reasons.
